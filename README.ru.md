# OpenCorel — экспериментальный векторный редактор на Rust

OpenCorel разрабатывается как независимая альтернатива для работы с рекламными макетами, плакатами и картами, включая большие размеры листов. Проект открыт для сообщества.

**Текущий этап: прототип 0.1.** В репозитории размещены модель документа в миллиметрах, настольный GUI, CLI, собственный формат OCD и базовый экспорт SVG. CorelDRAW CDR/CMX, PDF/X, CMYK и полноценный текстовый движок пока **не поддерживаются**.

## Запуск

Требуются Rust stable и системные зависимости Rust/eframe. Windows 10/11 x64 и Linux x64 — первичные цели. Windows 7 является отдельной экспериментальной целью и не проверена.

Запустите: cargo run --release -p opencorel-desktop

Тесты: cargo test --workspace

CLI: cargo run -p opencorel-cli -- new example.ocd

Пока не заявляем совместимость с CorelDRAW и не рекомендуем использовать в производстве. GitHub Actions проверит компиляцию и тесты после коммита. Правила участия находятся в CONTRIBUTING.md, а план — в docs/ROADMAP.md.

**Важно:** OpenCorel — внутреннее рабочее имя, не связанное с Corel Corporation; перед публичным распространением нужен анализ товарного знака.

## Новые возможности разработки (ветка main, предварительная версия)

- Кривые Безье: построение щелчками, редактирование контрольных точек в свойствах, экспорт SVG.
- Слои: создание, выбор, видимость и блокировка; старые OCD открываются с основным слоем.
- Отмена/повтор: Ctrl+Z, Ctrl+Y / Ctrl+Shift+Z; до 50 состояний.
- Фигуры создаются протягиванием мыши, навигация — колесом и средней кнопкой.
- Управление порядком объектов, дублирование, удаление; Ctrl+S и Ctrl+O.

Это ранние функции без проверки печатного процесса. GitHub Actions собирает Windows/Linux. Импорт CDR, экспорт CDR, PDF/X, CMYK и Windows 7 пока не готовы.
