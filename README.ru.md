# OpenCorel — открытый векторный редактор на Rust

**Версия исходников: альфа-прототип (текущая версия указывается в `Cargo.toml`).** Разрабатываем независимый инструмент для рекламных макетов, больших плакатов, карт и вывесок на Windows 10/11 и Linux.

[Руководство по работе](docs/USER_GUIDE_RU.md) · [Компактная панель инструментов](docs/UX_COMPACT_TOOL_DOCK.md) · [Актуальная таблица форматов](docs/FORMAT_SUPPORT.md) · [Формат KDR](docs/KDR_SPEC.md) · [Формат библиотеки OCLIB](docs/OCLIB_SPEC.md) · [Матрица приёмки](docs/QA_MATRIX.md) · [Правила участия](CONTRIBUTING.md) · [План](docs/ROADMAP.md)

## v0.23 alpha — Связанные символы и локальная библиотека компонентов

- **Создание символа из выделения.** Один или несколько обычных объектов с одного видимого, незаблокированного слоя превращаются в связанный компонент; исходная группа становится первым экземпляром. Clipping-объекты и уже сгруппированные элементы не принимаются. Ограничение — 500 объектов на символ.
- **Локальная библиотека OCLIB.** Автоматическое сохранение в пользовательской папке данных, поиск по названию и категории, импорт и экспорт переносимых библиотек. До 512 ресурсов, 64 МиБ на файл.
- **Вставка экземпляров.** Вставленный компонент остаётся набором обычных векторных объектов, объединённых группой; никакого нового непрозрачного типа Shape не добавляется.
- **Обновление по источнику.** Команда «Обновить определение из выделенной группы» заменяет содержимое определения и синхронизирует все связанные экземпляры в документе, сохраняя положение и габариты каждого экземпляра.
- **Разрыв связи.** «Разорвать связь, оставить группу» превращает выбранный экземпляр в обычную группу без потери геометрии.
- **Сохранение связи в рабочих сценариях.** KDR, Undo/Redo, Ctrl+C/Ctrl+V, дублирование, массивы, копирование и перенос между страницами сохраняют связь. Удаление или разгруппировка экземпляра корректно отсоединяют его.
- **Совместимость.** Старые KDR-файлы читаются благодаря полям с serde-default; версия схемы KDR не меняется. SVG/PDF получают обычную векторную геометрию, без внешней зависимости от OCLIB.
- **Ограничения альфа-версии.** Не поддерживаются вложенные символы и независимые переопределения отдельных объектов. Узлы можно редактировать инструментом «Узлы» внутри связанного экземпляра; после этого обновите определение из выделенной группы. При обновлении геометрия масштабируется под прежнюю рамку остальных экземпляров. CMYK/ICC и полная CDR-совместимость по-прежнему не заявляются.

## v0.22 alpha — Надёжность проекта и восстановление после сбоя

- **Автосохранение KDR.** Для изменённого документа создаётся отдельный атомарный снимок по 45-секундному интервалу; запись откладывается, пока с последнего изменения не прошло минимум 2 секунды. Исходный файл не перезаписывается, формат проекта и его контрольная сумма остаются прежними.
- **Восстановление сеанса.** При следующем запуске редактор ищет последнюю корректную резервную копию. Её можно восстановить как отдельный документ или удалить; оригинал на диске не заменяется.
- **Защита от потери изменений.** Перед созданием нового документа, открытием другого файла и закрытием окна появляется выбор: сохранить, отказаться от изменений или отменить действие. Если диалог «Сохранить как» закрыт без сохранения, исходное действие не выполняется.
- **Диагностика сбоев.** Rust panic hook сохраняет отдельный текстовый отчёт с версией, временем и местом сбоя. Содержимое документа и встроенные изображения в отчёт не попадают.
- **Проверки:** атомарность recovery-снимка, чтение/валидация KDR, dirty-state, Undo/Redo и блокировка деструктивных действий.

Автосохранение — это резервная копия, а не замена Ctrl+S. Ручная проверка сценариев аварийного завершения и восстановления на реальных Windows/Linux системах обязательна.

## v0.21 alpha — Векторный QR, глобальная палитра и навигатор объектов

Обновление интегрирует сразу три рабочих подсистемы для многостраничной полиграфии и рекламных проектов:

- **Генератор QR-кодов без интернета.** Верхнее меню «Производство+ → Векторный QR-код». Поддерживаются произвольные URL/тексты в UTF-8 до 1024 байт, четыре уровня коррекции ошибок и размер до 2 метров. Превью рисует тот же векторный контур, который создаётся в документе. На листе появляются **два редактируемых векторных объекта в группе** — светлая подложка с 4-модульной свободной зоной и набор тёмных квадратных контуров. Это не растровая картинка, QR сохраняется в KDR и выводится в SVG/PDF. Минимальный размер модуля 0,3 мм и контроль контрастности уменьшают вероятность нечитаемых кодов; итоговый скан необходимо проверить камерой.
- **Глобальная замена цветов.** «Производство+ → Массово заменить RGB»: отдельно заливки, контуры и точки градиентов; активная страница или все 64 страницы. Предпросмотр точно считает затрагиваемые объекты, слоты и страницы. Заблокированные/скрытые совпадения отменяют всю операцию без частичных изменений. Вся замена отменяется одним Ctrl+Z. Можно выбрать все объекты одного цвета на активном листе.
- **Навигатор объектов.** «Производство+ → Найти объекты»: поиск по имени, текстовому содержимому, типу (текст, векторы, фото, встроенные SVG, группы), имени слоя и RGB-цвету. Работает по активной или всем страницам; щелчок по результату открывает страницу и выделяет объект.
- **CLI и тестирование:** новые команды `qr-code`, `recolor-rgb`, `find-objects`; регрессионные тесты редактируемости QR, сериализации, Unicode-поиска, цветовых операций, заблокированных слоёв, Undo и сквозного SVG-экспорта.

**Ограничения:** нет полной редактируемости CDR, CMYK/ICC/PDF/X, автоматического сканирования QR камерой, OpenType shaping уровня CorelDRAW и подтверждённой совместимости Windows 7. Печатные QR нужно проверять конечным сканирующим устройством.

## v0.20 alpha — большое обновление редактора

**Редактор градиентов:** семь RGB-пресетов («Рассвет», «Океан», «Лес», «Закат», «Сталь», «Неон», «Ч/Б»), от 2 до 32 цветовых точек, угол, линейная/радиальная заливка, предпросмотр, добавление точек нажатием, точные проценты и HEX. Редактирование существующего объекта, сохранение в KDR и экспорт SVG/PDF.

**Текст:** поиск и замена на одной или всех страницах через Ctrl+F/Ctrl+H, включая кириллицу. Результаты открывают страницу и выбирают надпись. Замена проверяет заблокированные слои, сохраняет стили и отменяется одним Ctrl+Z. Доступны прописные, строчные, «Каждое Слово» и регистр предложений.

**Контуры:** преобразование прямоугольника, эллипса и ломаной в кубические кривые Безье; упрощение открытых ломаных с допуском, соединение двух открытых контуров при совпадении слоёв, оформления и концов. Действия проверяют группы, маски и блокировки.

**Паспорт макета:** по запросу показывает на всех страницах используемые цвета, шрифты, градиенты, растровые и встроенные векторные объекты, группы и маски.

**CLI:** команды `inventory`, `find-text`, `replace-text`, `gradient-preset`. Замена текста сохраняет новый KDR, не перезаписывая источник.

Это всё ещё альфа: нет полноценного CDR, ICC/CMYK, PDF/X, сложной типографики уровня Corel и подтверждённой работы на Windows 7.

## v0.19 alpha — Drawing & Production Mega Update

Ещё одна крупная итерация — инструменты рисования, точное выделение,
производственные аннотации и экспорт.

- **Карандаш (F)** — интерактивная свободная линия из движений мыши,
  настраиваемые толщина, цвет и сглаживание Рамера—Дугласа—Пекера.
  Результат — обычный векторный контур с доступными узлами (F10), KDR/SVG,
  Undo. Предусмотрены лимиты на число точек и допустимые координаты.
- **Выделение рамкой (V)** — справа налево выбираются все объекты,
  которые пересекаются с рамкой; слева направо — только полностью
  содержащиеся в ней. Shift добавляет к выделению, группы и запреты
  заблокированных/скрытых слоёв учитываются.
- **Пипетка (I)** — образец заливки, обводки, прозрачности,
  градиента, пунктирной обводки, а для текста — текстового оформления.
  Сначала выберите цели, затем щёлкните по образцу.
  Ctrl+Shift+C копирует оформление в независимый буфер программы,
  Ctrl+Shift+V применяет его к выделению. Всё поддерживает Undo.
- **Размерные линии** — выделите один объект и выберите «Ш, мм» или
  «В, мм» в контекстной панели. На листе создаются редактируемые
  векторные линии, засечки и текст с реальным размером в миллиметрах;
  сгруппированы, сохраняются в KDR, попадают в SVG/PDF.
- **Масштаб выделения** — приблизить и расположить выбранные объекты
  по центру видимого холста, с учётом действительного размера окна.
- **Пробный экспорт с метками реза** — SVG и RGB PDF на увеличенном
  листе, с 8 векторными метками за границами реза.
  Документ не меняется; регулировка полей 8–40 мм через Центр экспорта.
  CLI: `export-trim-svg` и `export-trim-pdf`.
  Важно: метки НЕ создают вылеты изображения под обрез,
  цветоделение CMYK или PDF/X.
- Регрессионные тесты геометрии, сглаживания и операций на слоях,
  границ рамки, оформления, отмены, размеров и экспорта.

Полная совместимость CDR, CMYK/ICC/PDF/X, прямое управление
плоттерами и Windows 7 остаются отдельными задачами.
Комплексное ручное тестирование на реальных дизайнерских проектах
по-прежнему необходимо.

## v0.18 alpha — Studio / Production Mega Update

Следующее крупное обновление объединяет несколько реальных подсистем редактора,
а не переименовывает мелкие изменения в отдельные версии.

- **Направляющие на каждой странице KDR** — хранятся вместе с проектом,
  рисуются только на экране, создаются щелчком по линейкам или точным вводом X/Y,
  редактируются и удаляются через «Лист → Направляющие». Привязка к направляющим,
  краям и центру листа, границам и центрам объектов, а также сетке.
- **Редактор объектов и слоёв** — переименование и изменение порядка слоёв,
  перенос выделения между слоями с защитой групп и заблокированных объектов,
  выбор всех объектов слоя, пошаговый подъём/опускание по Z.
- **Межстраничные операции** — копирование и перенос выделенных объектов на
  другие страницы с сохранением групп, стилизации, обтравки и раздельных слоёв.
  Пункт «Страницы» в верхнем меню. Для надёжности требуются все объекты группы
  и обе стороны связи маски.
- **Настоящий единый многостраничный PDF** — кнопка в «Центре экспорта»
  собирает страницы в одном PDF-файле с отдельными ресурсами; независимая
  проверка парсером pypdf в CI. По-прежнему RGB, не PDF/X и не CMYK.
- **Инструменты стали видимыми** — прямые иконки выделения, узлов, текста,
  Безье, прямоугольника, эллипса, линии, многоугольника. Ещё 19 фигур —
  в отдельном выпадающем меню. Каждая иконка нарисована средствами egui,
  без зависимости от установленных графических шрифтов.
- **Палитра команд Ctrl+K** — поиск более 35 реальных действий редактора,
  включая работу со страницами, файл, экспорт, выбор инструментов и геометрию.
  **Ctrl+PageUp/PageDown** переключает страницы, **PageUp/PageDown**
  меняет порядок выделенных объектов.
- **Предпечатная проверка всей публикации**, а не только текущей страницы:
  ошибки и предупреждения отмечены именем страницы.
- **CLI**: `opencorel-cli export-pdf-book BOOK.kdr merged.pdf`.
  Автоматическая проверка KDR, независимое чтение экспортированного PDF
  и компиляция Windows/Linux включены в CI.

Ограничения: аппаратные тесты принтеров, графических планшетов, плоттеров
и сканеров ещё не проводились. CDR-импорт экспериментальный, CDR-экспорта нет;
ICC/CMYK/PDF/X, мастер-страницы, полная типографика и вложенные группы ещё
не реализованы. Совместимость Windows 7 не подтверждена.

## v0.17 alpha — Professional Workspace Mega Iteration

Одна итерация — три больших блока:

- **Нативные многостраничные документы.** До 64 независимых страниц с
  собственными объектами, слоями, связями обтравки и размерами. Добавление,
  удаление, дублирование, переименование и переход между страницами. Старые

- **Рабочее пространство.** Реальные вкладки страниц под холстом, панель

  Структурные операции поддерживают Ctrl+Z, а смена страницы сбрасывает
  временные выделения, узлы и кэши отображения.
- **Центр экспорта.** Пакетный SVG, PDF (RGB), PNG и JPEG по выбранным
  страницам, настройка DPI для растра. Файлы сначала готовятся во временной
  папке, а существующие не перезаписываются.

CLI-команды: `pages`, `add-page`, `duplicate-page`, `batch-svg`,
`batch-pdf`. Прогоняются в Windows/Linux CI.

**Границы реализации:** отдельный файл PDF на страницу (не один общий);
слои независимы для каждой страницы; мастер-страницы и полноценная CDR/CMYK
совместимость не реализованы.

## v0.16 alpha — DXF для CAD / лазера / CNC

- **Оборудование → Лазер / CNC — DXF R2000**: экспорт открытых и замкнутых
  2D-контуров в DXF R2000 (AC1015). Сохраняются имена видимых слоёв документа
  в безопасных ASCII-именах DXF; слой 0 добавляется автоматически.
- Единицы: миллиметры (по умолчанию) или дюймы; начало координат снизу слева
  (CAD Y вверх) либо сверху слева; смещение X/Y и допуск аппроксимации кривых
  от 0,01 до 2 мм (по умолчанию 0,10 мм).
- Прямоугольники, эллипсы, ломаные, кривые Безье и составные контуры
  экспортируются как DXF POLYLINE. Отверстия составных контуров остаются
  отдельными замкнутыми контурами на том же слое.
- Предварительная проверка показывает количество полилиний, вершин, слоёв
  и суммарную длину геометрии. Скрытые слои не экспортируются.
- CLI: `opencorel-cli dxf-preflight design.kdr` и
  `opencorel-cli export-dxf design.kdr machine.dxf`.
- **Ограничения:** текст нужно преобразовать в кривые; растр, размещённые SVG,
  clipping и эффекты не экспортируются. DXF не содержит скоростей, мощности,
  глубины реза или G-code. Перед реальной обработкой откройте файл в CAD/CAM,
  проверьте масштаб, начало координат и назначение операций по слоям.
  Физические испытания с лазерными и CNC-станками ещё не проводились.

## v0.15 alpha — плоттеры и производственная периферия

- **Оборудование → HP-GL/1:** экспорт `.plt` для плоттеров и режущих устройств,
  поддерживающих классические команды HP-GL. Это файл для проверки и последующей
  подачи через совместимое ПО или драйвер производителя; **прямого управления
  USB, сетью, ножом, скоростью или давлением пока нет**.
- Поддерживаются контуры прямоугольников, эллипсов, ломаных, кривых Безье
  и составных фигур с отверстиями. Ведётся адаптивная аппроксимация кривых
  с задаваемым допуском, по умолчанию 0,15 мм.
- Параметры: перо 1–8, единицы плоттера на миллиметр (по умолчанию 40),
  начало координат сверху/снизу слева, смещение XY, все контуры или только
  объекты с обводкой.
- Предварительный контроль сообщает число контуров, вершин, длину реза,
  длину холостого хода и количество пропущенных объектов без обводки.
  Не допускает выход за границы листа, отсутствующие траектории,
  неподготовленный текст, растровое изображение или обтравку.
- CLI: `opencorel-cli plotter-preflight design.kdr` и
  `opencorel-cli export-plt design.kdr cutting.plt`.
- **Безопасность:** программа не запускает станок. Перед резкой сделайте
  пробный прогон без инструмента / на тестовом материале и проверьте
  начало координат, масштаб и совместимость HP-GL с моделью оборудования.
  Драйверы конкретных брендов, метки оптической резки и протоколы
  Graphtec/Roland/DMPL, а также TWAIN/WIA и CMYK пока не поддерживаются.

## v0.14 alpha — параметрическая геометрия и массивы (в разработке)

- Меню **«Фигуры+»**: 19 видов нативных редактируемых векторных форм, включая звезду,

- Меню **«Массивы»**: линейное повторение, прямоугольная сетка и круговое размножение.
  Выделенные объекты копируются с сохранением базового оформления, шрифтов, групп
  и внутренних связей обтравки. Оригиналы остаются неизменными.
- Все операции используют один шаг Undo; недопустимые параметры и
  невозможные трансформации не должны оставлять частично созданных объектов.
- **Ограничения:** максимальное число новых объектов в одной операции — 1500;
  произвольное вращение текста/растровых изображений не реализовано.
  Параметрический объект после создания превращается в обычный редактируемый
  путь — изменение числовых параметров после создания пока не сохраняется.
- Выпуск считается проверенным только после успешного CI и проверки GUI.

## Обновлённый интерфейс инструментов

Большие вертикальные кнопки и постоянный блок инструкций больше не занимают левую часть экрана. **По умолчанию слева компактная панель шириной около 64 пикселей** — основные действия (выделение, узлы, текст, кривая), импорт фотографий и проверка макета. Прямоугольник, эллипс, линия и шестиугольник объединены в меню **«Фигуры»**.

- **» / «** вверху панели переключает компактные и расширенные подписи. Инструменты остаются доступны клавишами `V`, `F10`, `F8`, `B`, `F6`, `F7`, `L`, `P`.
- Наведите указатель на значок — появится русская подсказка с назначением и сочетанием клавиш.
- **F9** скрывает/возвращает правую панель «Свойства», чтобы освободить холст; вкладки можно вновь открыть из меню **«Окно»**.
- Параметры активного инструмента появляются **справа**, в «Свойствах»: содержимое создаваемого текста, точные X/Y выбранного узла.
- Редкие действия (образец макета, копирование, вставка и подсказка про маски) спрятаны в **«Действия»**, подробное обучение открывается по `F1`.
- Другие команды никуда не пропали: меню **«Контуры»**, **«Маски»**, **«Объект»**, экспорт и инструменты документа остаются в верхней строке.

Документация: [принципы дизайна и проверки](docs/UX_COMPACT_TOOL_DOCK.md).

## Что нового в v0.10 — логические операции над фигурами

- В меню **«Контуры»** доступны: объединение, вычитание второй фигуры из первой, пересечение и симметрическая разность (XOR).
- Выберите две фигуры с **Shift**. **Первая** выбранная фигура — A; **вторая** — B. Для вычитания порядок имеет значение.
- Результат — обычный редактируемый составной векторный контур (KDR), сохраняющий отверстия, отдельные островки и заливку первой фигуры.
- Поддерживаются прямоугольники, эллипсы, замкнутые многоугольники и кривые Безье. Шрифты сначала преобразуйте в кривые; открытые линии и изображения пока не поддерживаются.
- Для устойчивости на слабых компьютерах действует ограничение сложности, а геометрия кривых аппроксимируется с целевой погрешностью не более 0,1 мм. Из-за преобразования в ломаные точная исходная параметризация кривых не сохраняется.
- При ошибке, пустом результате, заблокированном слое и непригодной фигуре исходники остаются в макете. После успеха **Ctrl+Z** восстанавливает оба исходных объекта.
- Полноценные маски, булевы операции с обводками и неразрушающие эффекты ещё не реализованы.

Подробности: [инструкция](docs/USER_GUIDE_RU.md) и [заметки v0.10](docs/RELEASE_NOTES_V010.md).

## Что нового в v0.9 — узлы прямо на листе
- Кнопка **«Редактирование узлов» (F10)** в панели инструментов.
- Перетаскивайте опорные точки и управляющие рычаги кривых Безье и составных контуров, а также вершины ломаных.
- Двойной щелчок на сегменте добавляет новый узел, для Безье применяется математически точное деление без изменения формы исходной кривой.
- `Delete` удаляет выбранный опорный узел (не целый объект); стрелки сдвигают его на 1 мм, Shift+стрелки — на 10 мм.
- Все изменения отменяются через `Ctrl+Z` и сохраняются в `.kdr`. Заблокированные слои и сгруппированные элементы не редактируются напрямую — группу предварительно разгруппируйте.
- [План на 20 итераций](docs/ROADMAP_20_ITERATIONS.md) задаёт последовательность дальнейших разработок и обязательные проверки.

## Что нового в v0.8 — профессиональная рабочая среда
- Новая компактная тёмная тема: единая графитовая палитра, бирюзовые акценты, понятное выделение групп, согласованные панели и кнопки. Светлая тема сохраняется.
- **Группировка и разгруппировка** объектов (`Ctrl+G` и `Ctrl+Shift+G`). Группа выделяется и двигается вместе, сохраняется в `.kdr`, при дублировании создаётся независимая копия группы.
- **Название объекта и поиск:** можно назвать элементы «Логотип», «Фон», «Заголовок» и находить их по поиску во вкладке «Объекты».
- **Точные координаты и размеры:** в свойствах объекта доступны X/Y и ширина/высота в миллиметрах; выделение можно центрировать на листе.
- **Изменяемый шаг сетки** от 0,5 до 1000 мм для чертежей, схем, баннеров и карт.
- Выделенные группы можно перемещать в порядке наложения на передний/задний план. Изменение или удаление группы не выполняется частично, если её элемент находится в недоступном слое.
- **Совместимость:** старые `.kdr` без имён и групп загружаются автоматически с пустыми названиями и без групп.

Руководство: [работа с объектами и группами](docs/USER_GUIDE_RU.md).

- **Изменение размера мышью** через угловые ручки (Shift сохраняет пропорции); перемещение через перетаскивание или клавиши-стрелки, Shift+стрелки — 10 мм.

## Запуск
Требуются Rust stable и зависимости GUI. В Linux могут потребоваться пакеты GTK3, X11 и Wayland.

```sh
cargo test --workspace
cargo run --release -p opencorel-desktop
```

CLI-примеры:

```sh
cargo run --release -p opencorel-cli -- new poster.kdr
cargo run --release -p opencorel-cli -- inspect poster.kdr
cargo run --release -p opencorel-cli -- convert simple.svg poster.kdr
cargo run --release -p opencorel-cli -- convert old_project.ocd new_project.kdr
cargo run --release -p opencorel-cli -- convert job.cdr job.kdr
cargo run --release -p opencorel-cli -- export-pdf poster.kdr proof.pdf
cargo run --release -p opencorel-cli -- export-bitmap poster.kdr proof.png 150
```

Для импорта CDR нужен установленный **LibreOffice**, а для большинства сложных векторных форматов и PDF — также **Poppler (pdftocairo)**. Запись обратно в CDR **не поддерживается**. Если конвертер не установлен, будет сообщение об ошибке, а не ложное успешное открытие.

## Статус качества
Это прототип для разработки и испытаний, **не 100% совместимая замена CorelDRAW**. Некоторые форматы открываются только как единое размещённое изображение без редактирования внутренних объектов. Профессиональная типографика, многостраничность, CMYK, PDF/X, расширенное редактирование изображений и Windows 7 ещё требуют отдельной разработки.

Оригинальные файлы заказчиков не удаляйте и не заменяйте на результаты конвертации без сравнения. Требуются обезличенные CDR из используемых вашей компанией версий для полноценного тестирования совместимости.
