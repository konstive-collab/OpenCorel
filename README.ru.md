# OpenCorel — открытый векторный редактор на Rust

**Новая рабочая версия: прототип v0.4 (пакет разработки).** Разрабатываем независимый инструмент для рекламных макетов, больших плакатов, карт и вывесок на Windows 10/11 и Linux.

[Актуальная таблица форматов](docs/FORMAT_SUPPORT.md) · [Формат KDR](docs/KDR_SPEC.md) · [Матрица приёмки](docs/QA_MATRIX.md) · [Правила участия](CONTRIBUTING.md) · [План](docs/ROADMAP.md)

## Что уже реализовано
- Интерфейс с привычной компоновкой профессионального векторного редактора: левый тулбар, меню, линейки, панели свойств, слои и цветовая палитра.
- Фигуры, текст, кривые Безье, управление порядком объектов, сетка, привязка, панорамирование, масштабирование, отмена и повтор.
- **.kdr (Kodi Draw)**: основной редактируемый формат, ZIP с документом и превью, версией и проверкой SHA-256; старые .ocd читаются.
- SVG/SVGZ-импорт, частичный перевод фигур/кривых в редактируемые объекты. При неподдерживаемых эффектах рисунок может сохраняться как единый векторный объект (не редактируются его внутренние элементы).
- Экспериментальные адаптеры для CDR, CMX, PDF, AI, EPS, ODG, DXF, WMF, EMF, WPG, Visio и др. См. [точный статус](docs/FORMAT_SUPPORT.md).
- Вставка фотографий/логотипов PNG/JPEG внутрь векторного документа (WebP, GIF, BMP и TIFF импортируются с преобразованием в PNG), перетаскивание файлов мышью.
- Множественное выделение Shift, Ctrl+A, выравнивание, равномерное распределение, групповое перемещение, пакетная смена цветов и удаление.
- Экспорт макета в PNG/JPEG для согласования с выбором 36–300 DPI (ограничение 24 Мп / 10 тыс. пикселей на сторону).
- Ограничение памяти истории изменений, кэширование миниатюр и безопасная запись KDR с крупными изображениями.
- Экспорт SVG и RGB PDF для проверки, но **не подготовка к типографии**.
- Автоматические тесты и сборки Windows/Linux, утилита пакетного преобразования.

## Запуск
Требуются Rust stable и зависимости GUI. В Linux могут потребоваться пакеты GTK3, X11 и Wayland.

```sh
cargo test --workspace
cargo run --release -p opencorel-desktop
```

CLI-примеры:

```sh
cargo run --release -p opencorel-cli -- new poster.kdr
cargo run --release -p opencorel-cli -- inspect poster.kdr
cargo run --release -p opencorel-cli -- convert simple.svg poster.kdr
cargo run --release -p opencorel-cli -- convert old_project.ocd new_project.kdr
cargo run --release -p opencorel-cli -- convert job.cdr job.kdr
cargo run --release -p opencorel-cli -- export-pdf poster.kdr proof.pdf
cargo run --release -p opencorel-cli -- export-bitmap poster.kdr proof.png 150
```

Для импорта CDR нужен установленный **LibreOffice**, а для большинства сложных векторных форматов и PDF — также **Poppler (pdftocairo)**. Запись обратно в CDR **не поддерживается**. Если конвертер не установлен, будет сообщение об ошибке, а не ложное успешное открытие.

## Статус качества
Это прототип для разработки и испытаний, **не 100% совместимая замена CorelDRAW**. Некоторые форматы открываются только как единое размещённое изображение без редактирования внутренних объектов. Профессиональная типографика, многостраничность, CMYK, PDF/X, расширенное редактирование изображений и Windows 7 ещё требуют отдельной разработки.

Оригинальные файлы заказчиков не удаляйте и не заменяйте на результаты конвертации без сравнения. Требуются обезличенные CDR из используемых вашей компанией версий для полноценного тестирования совместимости.
