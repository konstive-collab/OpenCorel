# Contributing to OpenCorel

Thank you for helping build an independent, resource-efficient vector editor!

## Where to start

1. Read [the roadmap](docs/ROADMAP.md) and [format status](docs/FORMAT_SUPPORT.md).
2. Pick an existing issue or describe a new improvement before a large change.
3. Fork the repository and create a feature branch.
4. Use Rust stable; run cargo fmt --all, cargo test --workspace and cargo clippy --workspace --all-targets.
5. Open a PR with a short rationale, screenshots for UI changes and regression tests for bug fixes.

## Contribution requirements

- Contribute code and artwork you wrote or have sufficient rights to contribute.
- No copied proprietary CorelDRAW code, icons, documentation, internal assets, or leaked format specifications.
- Compatibility research should rely on lawfully obtained samples and permitted independent analysis.
- Do not commit customer documents, company maps, fonts or confidential artwork.
- Keep Linux and Windows support; Windows 7 work must be explicitly tested on old machines.
- Submit changes under the repository MIT license.
- Discuss breaking document-format changes before implementation.

## Areas needing contributors

Vector geometry and Bézier paths; fonts and typography; document interoperability; SVG import; PDF/X and ICC printing; translations; legacy Windows compatibility; QA and performance benchmarks.

## Language

English or Russian are both welcome in issues and pull requests.
