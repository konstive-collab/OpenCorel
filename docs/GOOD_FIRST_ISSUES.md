# Suggested community contributions

**Small, testable tasks**
- Improve error strings and translations of GUI labels.
- Add tests for negative sizes, invalid colors and malicious JSON inputs.
- Add several documented SVG output reference examples.
- Make keyboard controls work with selected shapes and text.
- Benchmark 100, 1,000 and 10,000 shapes on Windows and Linux.
- Document packaging on Linux; avoid proprietary assets.

**Larger tasks needing a design proposal**
- Bezier path representation, node editing and path boolean operations.
- Proper text shaping with kerning and font substitution.
- Layer/group design and efficient scene indexing.
- Color profiles and CMYK/PDF/X export.
- Version-based CDR fixture corpus and lawful read-only import research.

All external document test files should be appropriately licensed and anonymized.
