# Security Policy

This is an experimental prototype and must not yet be used for sensitive production documents.

Report suspected vulnerabilities privately to repository maintainers using GitHub's private vulnerability reporting where enabled. Avoid publishing exploits or confidential test documents in public issues.

Known limitations: no hardened document parser for untrusted CDR/PDF/AI inputs (these formats are not implemented); no atomic save or crash recovery; no signed releases or dedicated Windows 7 security support.
